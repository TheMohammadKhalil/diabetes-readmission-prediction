1 · Choose using training data

Which model performed best across five folds?

Average precision measures how well a model ranks the uncommon readmissions. Higher is better. Each gray dot is one validation fold; the square and bar show the mean and one standard deviation. Green marks the selected gradient boosting model.

The bars show fold variation, not confidence intervals. Hyperparameters were selected using these same folds, so these are development estimates.

2 · Check on unseen patients

How did the frozen models perform?

These results use the 19,718 held-out encounters. Each model uses its saved training-selected cutoff. Gradient boosting was chosen before seeing these results.

The dashed average-precision reference is the 11.10% positive prevalence. Small model differences are not evidence of statistical significance.

3 · Explore training predictions

What happens when we change the cutoff?

A score at or above the cutoff becomes a positive prediction. A lower cutoff usually catches more readmissions, but also flags more encounters that do not lead to early readmission.

Training out-of-fold predictions only — 79,625 encounters. Each score was produced while that patient's records were outside the fitted fold. Exploring here does not change the paper's fixed test results.
